# Agent notifications

T3 Code on web and desktop can post a system notification when an agent finishes a
turn, needs an approval, asks you a question, or fails. Click a notification to open
its thread.

Turn it on in **Settings → General → Notifications** with **Notify me about agents**.
Your browser or macOS asks for notification permission the first time. Each kind can
be switched off on its own, and **Only while T3 Code is in the background** (on by
default) keeps the app quiet while you are looking at it.

Notifications come from the window you have open, so they stop when every T3 Code
window is closed. For alerts on your phone, see [Mobile notifications](mobile-notifications.md).
