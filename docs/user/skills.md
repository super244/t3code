# Skills

Open **Settings → Skills** to inspect reusable agent instructions installed on each connected
computer. T3 Code groups installations by provider instance, so the same skill can appear separately
for different harnesses or subscriptions.

The inventory currently discovers global Codex and Claude skills and shows the skill name,
description, source directory, and `SKILL.md` content. Search matches names, descriptions, harnesses,
and paths. The inventory is read-only: install or edit a skill in the harness's normal configuration
directory, then choose **Refresh all**.

Project-specific skills continue to appear in the composer for the active project. The global
inventory does not replace provider-native enablement or invocation rules.
